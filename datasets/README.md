# Datasets

Datasets are downloaded locally and are never committed to this repository. The `.gitignore` excludes everything in this directory except this README.

## HERIDAL

- Name: HERIDAL, a dataset of aerial images for search and rescue of people in wilderness areas.
- License: CC-BY-3.0. Attribution is required wherever results derived from it are published.
- Source and DOI: https://zenodo.org/records/5662351 (Zenodo record 5662351, DOI 10.5281/zenodo.5662351).
- Place the extracted files under `datasets/heridal/`. That path is ignored by git.

Any benchmark document must cite HERIDAL and state its license.
